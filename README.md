# Regex Patterns Practice

A collection of Python exercises exploring regular expressions, functional programming patterns, and data extraction techniques.  
This project demonstrates how to use `re`, `map`, `filter`, `reduce`, and comprehensions to process structured and unstructured text data.

## Features

- Extract ZIP codes, state abbreviations, and other patterns using regex
- Use functional tools (`map`, `filter`, `reduce`) instead of loops
- Demonstrate safe regex matching using assignment expressions
- Practice dataset included for testing extraction logic
- 100% loop‑free functional transformations
